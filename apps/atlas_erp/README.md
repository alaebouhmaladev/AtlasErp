# ATLASERP extension

Frappe app for ATLASERP branding, guided navigation, country packs and ATLASUSE
integration. Install **after ERPNext**. Development baseline: matching Frappe and
ERPNext 17 development branches. No production compatibility is claimed yet.

The authenticated `/atlas` launchpad links to existing ERPNext workflows.
ATLASERP site branding applies on install/migration. The ERP engine supplies one
ATLASERP launcher entry; this companion app supplies the product experience.
It contains no sample revenue or fabricated financial metrics. Moroccan tax and
accounting configurations will be delivered only after professional validation.

See the root `ATLASERP.md` and `docs/atlas/` for setup, scope and the backlog.
